# DSH Studio 体验升级与文案品牌规范化 PRD

> **文档版本**：v1.0.0  
> **文档状态**：待审核 (Pending Review)  
> **责任角色**：PM / ARCH  

---

## 1. 背景与核心目标

### 1.1 背景说明
DeepSeek Harness (DSH) 已从早期的纯 Web 插件集合（`dsh-web-ui`）全面演进为跨平台的现代独立桌面应用 **DSH Studio (App)**。  
在现网使用与设置面板中，仍残留有部分旧命名（如 `dsh-web-ui`）、历史预设名称（如 `梁神模式`），以及桌宠伴侣在设置关闭后残留悬浮窗与后台漫步的体验缺陷。

### 1.2 核心目标
1. **品牌与文案一致性**：将全仓设置面板中面向用户的 `dsh-web-ui` 描述全面重塑为 **DSH Studio / Studio 增强插件**，并重构润色各项插件的描述文案。
2. **预设规范化**：将 Agent 预设中的 `梁神模式` 修正为 **`南梁模式`**。
3. **桌宠生命周期 Bug 修复**：彻底解决小鲸鱼姬桌面伴侣在「设置 > 小鲸鱼姬」切换为「已关闭」时，界面上依旧残留交互对话气泡、状态胶囊并持续在后台自主漫步的严重 Bug，确保关闭时 0 残留即时销毁。

## 2. 功能清单与需求细节 (Feature Scope)

### 2.1 模块 A：设置面板品牌文案全面重塑
* **范围**：「设置 > 插件」、「设置 > 插件配置」、「设置 > 社区插件」等全部 UI 视图。
* **原描述 1**：`Web UI 插件` / `统一管理 dsh-web-ui 全家桶插件的启用与配置。`
* **新描述 1**：`Studio 增强插件` / `统一管理 DSH Studio 全栈增强插件套件的启用与个性化配置。`
* **原描述 2**：`条目由贡献者自行登记，与 dsh-web-ui 的发布内容无关；使用前请自行评估。`
* **新描述 2**：`条目由贡献者自行登记，与 DSH Studio 的发布内容无关；使用前请自行评估。`
* **文案创造与润色**：为各子插件（移动端远控、皮肤中心、任务看板、实时令牌估算、图像理解）提供现代化、专业且生动的产品级描述。

### 2.2 模块 B：Agent 预设重命名
* **范围**：「设置 > Agent 预设」及底层 preset 注册配置文件。
* **原名称**：`梁神模式`（描述：`V4 Pro 专属，小南梁进化，梁神，启动！`）
* **新名称**：`南梁模式`（描述：`V4 Pro 专属，小南梁进化，南梁，启动！`）

### 2.3 模块 C：小鲸鱼姬桌面伴侣完全停用与即时销毁
* **范围**：`plugins/dsh-mascot-pet` 客户端组件。
* **现状 Bug**：关闭开关（`enabled: false`）时，仅隐藏了主立绘图片，但其对话气泡容器、Token 计费胶囊、漫步计时器（`MascotWanderEngine`）、闲置微动作计时器仍处于运行状态并在界面上漂移。
* **改进要求**：
  * 当 `enabled` 为 `false` 时，组件根节点立即返回 `null`，完全卸载（Unmount）所有 DOM 结构。
  * 漫步引擎与微动作调度器立即 `destroy()` / `clear()`，销毁所有事件监听与移动动画，无任何 CPU / 渲染开销与视觉残留。
  * 重新开启时无缝重新挂载并恢复正常动画。

## 3. EARS 验收标准 (Acceptance Criteria)

* **[EARS-01 插件设置]** **When** 用户打开「设置 > 插件」**the system shall** 显示「Studio 增强插件」，描述为「统一管理 DSH Studio 全栈增强插件套件的启用与个性化配置。」，且不再出现任何 `dsh-web-ui` 字样。
* **[EARS-02 社区免责]** **When** 用户滑动到「社区插件」底部 **the system shall** 显示「条目由贡献者自行登记，与 DSH Studio 的发布内容无关；使用前请自行评估。」。
* **[EARS-03 南梁预设]** **When** 用户打开「设置 > Agent 预设」**the system shall** 在自定义预设中显示「南梁模式」，卡片与预设选择器中均同步更新。
* **[EARS-04 桌宠关闭]** **When** 用户在「设置 > 小鲸鱼姬」中点击将「启用小鲸鱼姬桌面伴侣」置为「已关闭」**the system shall** 立即从屏幕上完全移除小鲸鱼姬、对话气泡与状态条，并立即终止所有坐标移动与漫步逻辑。
* **[EARS-05 桌宠重启]** **When** 用户在设置中重新点击开启伴侣 **the system shall** 立即在屏幕右下角恢复桌宠立绘与交互能力。
